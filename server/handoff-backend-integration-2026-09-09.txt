## 切換真 API 方法（前端零程式碼改動）

- `utils/api.ts`：`VITE_API_URL` env 優先，否則 fallback 到 same-origin（`window.location.origin`）
- 本機 dev：vite.config.ts:10-17 proxy `/api` → http://localhost:4000（跑真實 server 就得）
- **生產（Vercel 前端 + Railway 後端）**：vercel.json 只 rewrite 到 index.html、唔會 proxy /api，
  **必須喺 Vercel 設定 VITE_API_URL 指向 Railway 後端 URL**，否則前端會打自己 origin 攞唔到資料
- 倉內目前冇 .env / .env.example

## D. 2026-09-10 新增：AI 異常警示中心（server 改動，請 review SQL／交易正確性）

質量分析「AI 異常警示」由死路改為警示中心，`server/api/quizzes.ts` 有以下改動：

| 改動 | 位置 |
|---|---|
| `anomaly_flags_json` 由 flat `string[]` 改為結構化 flag 陣列（type/questionIndex/questionId/excerpt/reason/status/teacherComment/resolvedAt）；`detectAttemptAnomalies` 逐題偵測＋摘錄 | `ANOMALY_RULES`、`normalizeAnomalyFlags` |
| GET /api/quizzes/:id/grading-detail — flag 服務端 normalize（legacy `string[]` 相容）；`metrics.anomalyCount` 改只數 open | grading-detail |
| GET /api/teachers/me/grading-summary — 每測驗加 `botId/botName/questionCount/publishedAt/anomalyCount`（open-flag jsonb subquery，對 legacy 同結構化都適用） | grading-summary |
| **新** PATCH /api/quizzes/:id/attempts/:attemptId/anomalies/:flagIndex — 老師處理警示（resolved/dismissed＋選填評語）；teacher gate＋交易＋FOR UPDATE＋`q.teacher_id` 擁有權；只可由 open 轉 | 新 route |
