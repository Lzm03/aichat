# 測驗發佈跟 Bot + 主題 — UX/UI 設計

## 背景（現況）

1. 老師出題時只揀 **Bot**（`components/assessment/steps/Step1TextAndGrade.tsx` 嘅「發佈到 Bot」），
   測驗入 DB 只帶 `bot_id`，**完全冇主題概念**（`server/api/quizzes.ts` 冇任何 topic 欄位）
2. 學生喺 Bot 對話入面見到測驗 —— `GET /api/bots/:botId/active-quiz` 只按 `bot_id` 揀
   **最新發佈嗰一份**（`ORDER BY updated_at DESC LIMIT 1`）。所以同一個 Bot 再發佈一份新測驗，
   舊嗰份學生就永遠見唔到（成績／質量分析仲喺度，只係冇入口）
3. 知識地圖已經有**主題版本**（`character_topics`，每 Bot 最多 4 個；對話按 `conversations.topic_id`
   用對應版本知識；學生對話 header 已經有「選擇主題」）。**惟獨測驗冇跟上呢個維度**

結果：老師一個 Bot 開 4 個主題（例：英語語法第一課／閱讀第一課／聽力第一課），
測驗卻只有一個「當前」位 —— 同一時間只能有一課有測驗。

主題版本本身嘅 UX 見 [knowledge-map-topic-versions.md](knowledge-map-topic-versions.md)（唔重複）。

## 已拍板（2026-09-26）

| 決策 | 決定 | 影響 |
| --- | --- | --- |
| 主題係必揀定可選？ | **可選**，預設「不分主題」 | 舊 Bot 照出得題 |
| 「不分主題」嘅測驗喺邊度出？ | 該主題冇自己嘅測驗時先出（fallback），**包括主題被限定嘅學生** | 舊測驗行為零改變；亦係「學生做唔到舊測驗」唔成立嘅原因（見 [topic-scoped-audience.md](topic-scoped-audience.md)） |
| 同一主題可否同時多過一份「進行中」？ | **唔可以** | 維持現況：最新發佈嗰份做入口，舊嗰份成績照留 |
| 一份測驗可否同時發去多個主題？ | **唔支援**，但出提醒引導去「複製為草稿」再改主題 | 見「多主題嘅提醒」 |
| 發佈後可唔可以改主題？ | **可以**（詳情 Drawer） | 舊測驗全部冇主題，呢個係唯一補救入口 |
| 主題縮唔縮窄受眾（班級）？ | **縮窄**：受眾由 Bot 層改成 Bot × 主題層 | 大改動，已另出計劃：[topic-scoped-audience.md](topic-scoped-audience.md) |
| 「不分主題」嘅說明文案點寫？ | 講 **fallback** 準確語義：「學生喺未有自己測驗嘅主題傾偈時會見到」，**唔寫**「任何主題都見到」 | 4 句一齊改：揀選器說明、Step 1 說明、發佈成功、刪主題警告 |
| 舊嘅無主題測驗要唔要另外標示（例如「未設主題」）？ | **唔使**：同新「不分主題」資料上、行為上完全一樣，唔加 marker 欄位 | 要分就要 migration 做 backfill，為一個裝飾性 tag 唔值得 |

## 核心規則

1. **邊份測驗俾學生見到**：學生開對話時，按**當前對話嘅主題**揀測驗 ——
   該主題有已發佈測驗 → 出最新嗰份；冇 → 出「不分主題」最新嗰份；兩者都冇 → 唔出 banner
2. **每個（Bot, 主題）組合最多一份「進行中」**：再發佈新測驗，學生入口指向新嗰份；
   舊嗰份嘅作答紀錄、成績、質量分析、異常警示全部保留（同現況一致）
3. **主題一刪，測驗唔會消失**：掛喺該主題嘅測驗自動變返「不分主題」
4. **受眾**：測驗側**唔另做主題判定**。學生永遠企喺一個「可用主題」上面
   （[topic-scoped-audience.md](topic-scoped-audience.md) 第 2 節保證），測驗就按嗰個
   主題解析（規則 1）—— 規則 1 嗰句「當前對話嘅主題」已經隱含咗受眾。
   所以呢份設計唔使加任何受眾條件，亦唔好加（加就會有兩份判定，早晚漂移）。
   受眾縮窄係另一件事，以呢份嘅 `quizzes.topic_id` 做前置。

## 老師端 UX

### 1. 出題「測驗設定」（問題 1）

```text
┌─ 測驗設定 ─────────────────────────────────────────────┐
│ 發佈到 Bot   [英語小助手 ▾]                             │
│ 主題         [英語語法第一課 ▾]                          │
│              學生喺呢個主題傾偈時，就會見到呢份測驗         │
│ 目標年級     [S1 ▾]          題目數量 [10 ▾]            │
└───────────────────────────────────────────────────────┘
```

- 主題下拉：該 Bot 嘅主題（`預設` badge 跟返現有寫法）＋最底一項 **「不分主題」**。
  下面說明行跟住揀咗乜而變：
  - 揀咗主題 →「學生喺「英語語法第一課」傾偈時會見到呢份測驗。」
  - 揀「不分主題」→「學生喺**未有自己測驗嘅主題**傾偈時，會見到呢份測驗。」

  ⚠️ **唔可以寫「任何主題都見到」**：一份「不分主題」測驗只會喺「該主題冇自己測驗」
  嘅時候先出（核心規則 1 嘅 fallback）。任何主題一旦有咗自己嘅測驗，就會遮住佢。
  寫「任何主題」係對老師講錯後果 —— 佢會以為發一次就全科通行
- 該 Bot 未有主題 → 只顯示「不分主題」＋一句提示
  「呢隻 Bot 仲未有主題，想分主題就去知識地圖加返。」
- 換 Bot → 主題清單同選擇一齊重置

### 2. 出題「預覽與發佈」（問題 2）

```text
┌─ 發佈 ────────────────────────────────────────────────┐
│ 會發佈到：英語小助手 · 英語語法第一課        [更改]      │
│ ⓘ 學生喺「英語語法第一課」傾偈時會見到呢份測驗。           │
│                        [儲存草稿]   [發佈測驗]          │
└───────────────────────────────────────────────────────┘
```

- 成功確認框跟住講清楚目的地：「「英語語法第一課小測」已發佈到「英語小助手 ·
  英語語法第一課」，學生喺該主題傾偈時就會見到。」
- 發佈一刻主題已經冇咗 → 顯示「呢個主題已經冇咗，請重新揀」，
  唔好靜靜雞當「不分主題」發出去

### 3. 「我的測驗」（問題 3，`MyQuizzesView`）

- **已發佈卡**：「綁定 Bot」下面加一行主題（`主題：英語語法第一課`）；
  「不分主題」用淺灰字，唔搶眼
- **草稿卡**：一樣顯示，令老師知呢份草稿跟邊個主題
- **篩選**：卡片區頂加一行 pill（`全部｜英語小助手 · 語法第一課｜…`），
  **只在有 ≥2 個（Bot, 主題）組合嘅已發佈測驗時先出**；單一組合唔出，
  唔好為咗一個維度加常設控件
- 排序照舊（未批改行先）；唔按主題分組 —— 卡片已經有標籤，分組會令列表高低不一

### 4. 已發佈詳情（問題 4，`PublishedQuizDetailDrawer`）

- header：`綁定 Bot：英語小助手 · 主題：英語語法第一課`，後面一個「更改」
- 改主題對話框文案（講後果，唔講機制）：
  - 未有作答：「改主題之後，學生會喺新主題嘅對話度見到呢份測驗。」
  - 已有作答：「已有 N 位學生作答。改主題唔會影響已收到嘅答案同成績，
    但學生會改喺新主題先見到呢份測驗。」

**多主題嘅提醒**（拍板：唔支援一份測驗發去多個主題）。主題下拉係單選，
老師揀咗一個之後，如果佢想要多一個主題，喺下拉底部同 Drawer 出一個捷徑：

```text
主題  [英語語法第一課 ▾]
      ─────────────────────
      不分主題
      ℹ 想同一份測驗俾多個主題？[複製為草稿] 再改主題就得
```

- 唔好出多選 checkbox（做唔到就會被當成壞咗）；用「複製為草稿」係 Drawer 現有功能，
  零新機制

### 5. 主題刪除（問題 9）

```text
刪除「英語語法第一課」？
呢個主題有 2 份已發佈測驗。刪咗之後，佢哋會變成「不分主題」，
學生喺所有主題都會見到。
                          [取消]  [繼續刪除]
```

- 唔用「禁止刪除」：`conversations.topic_id` 已經係 `ON DELETE SET NULL`，
  測驗跟同一個做法係一致嘅；禁止反而令老師冇路走（4 個位滿咗又想開新主題）
- 呢個數字要唯讀查一次（topic 列表 API 順便回 `quizCounts`），
  唔好喺前端逐個主題打一次

## 邊界情況

| 情況 | 行為 |
| --- | --- |
| Bot 冇任何主題 | 主題揀選器只有「不分主題」；學生端行為同今日完全一樣 |
| 老師揀「不分主題」 | 充當**後備**：喺「該主題冇自己測驗」嘅主題先出。文案要照呢個講（見老師端 §1），唔可以寫「任何主題都見到」 |
| 舊已發佈測驗（老師從來冇揀過主題） | **零處理**：`topic_id` 全部係 NULL，同新揀嘅「不分主題」資料上、行為上都係同一個狀態；列表共用同一個淺灰 tag，唔加欄位分開顯示。想配返主題就用詳情 Drawer「更改」（見 §4） |
| 同一份測驗想俾兩個主題 | 唔支援；下拉底部出提醒引導「複製為草稿」→ 改主題 → 再發佈（兩份各自有作答紀錄） |
| 主題被刪 | 測驗變「不分主題」，唔會消失、唔會刪任何作答紀錄；刪之前已經警告過 |
| 草稿 | 一樣存主題（`topic_id` 喺草稿階段已經寫入），編輯草稿時帶返出嚟 |
| 方案限額（入門版 1 次發佈） | 唔變：限額係「發佈次數」，同主題無關 |
| 測驗封存 | 封存欄位（`archived_at`）**未喺呢條分支**，喺 `doris/quiz-archive`／[class-participation.md](class-participation.md) 提出。兩邊都上咗之後，「進行中測驗」查詢要排除已封存 —— 實作時先對返 main 有冇呢個欄位 |
